# Demo Cache (Fail-Safe Offline Mode)

This directory holds pre-rendered videos and samples for key STEM concepts:
1. `binary_search.mp4`
2. `pythagoras.mp4`

### Why this is crucial for the Hackathon:
As recommended in the Hacktoberfest guide:
> *"Practise it twice. Record a short screen video as a backup in case the Wi-Fi fails during your slot... A demo that only works if the Wi-Fi does is a beginner mistake to avoid."*

If the venue Wi-Fi drops or API rate limits trigger during your 3-minute pitch, the app can instantly stream pre-cached examples without crashing.
